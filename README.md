# Holliday Planner

დასვენების პერსონალური და ჯგუფური დაგეგმვის ვებაპლიკაცია.

მომხმარებელი უთითებს ინტერესებს, დანიშნულების ადგილს, თარიღებს, ბიუჯეტსა და თანამგზავრებს. აპლიკაცია აგროვებს ამინდისა და დანიშნულების მონაცემებს, ამზადებს AI რეკომენდაციას, ადარებს ალტერნატივებს და მომხმარებლის დადასტურების შემდეგ აგზავნის მოწვევებს.

## მიმდინარე ეტაპი

2026-11-10 — მომზადებულია საწყისი პროექტის გეგმა, საგამოცდო შესაბამისობის ცხრილი და ტექნიკური არქიტექტურის წინადადება. აპლიკაციის კოდის განხორციელება შემდეგი ეტაპია.

პროექტის სახელწერა შენარჩუნებულია მომხმარებლის არჩევანით — **Holliday Planner**.

## GitHub-ის სამუშაო პროცესი

პროექტს ექნება საკუთარი Git რეპოზიტორია და საკუთარი GitHub remote. განვითარების ცვლილებები შეინახება მცირე, შინაარსიანი commit-ებით. `.env` ფაილები, API გასაღებები, რეალური მოწვევები და მომხმარებლის პერსონალური მონაცემები Git-ში გამორიცხულია.
