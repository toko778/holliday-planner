## ტექნიკური შემოწმებები

პირველი ეტაპის ჟურნალები შენარჩუნებულია `P2.3-build.txt`, `P2.2-navigation-tests.txt` და `P2.3-preview-check.txt` ფაილებში. ანგარიშების ეტაპის ახალი შედეგები ინახება `P2.6-tests.txt` და `P2.6-build.txt` ფაილებში.

ანგარიშების ავტომატური ტესტები იყენებს სატესტო Auth კლიენტს. მოწმდება ვალიდაცია, დადასტურების მოთხოვნის მდგომარეობა, სესიის აღდგენა, ინტერესები, შესვლა/გასვლა, პაროლის აღდგენა და დუბლირებული მოთხოვნისგან დაცვა. Supabase-ის კავშირი ცალკე შემოწმებულია რეალური Auth settings მოთხოვნით. რეგისტრაციისა და წერილების სცენარი დარჩენილია დაბრუნების მისამართების გამართვის შემდეგ.

## ბრაუზერის შემოწმება

ლოკალური საიტი გაიხსნა `http://127.0.0.1:5173/` მისამართზე. გამოყენებულია 1440×1000, 768×1024, 390×844 და 320×800 viewport-ები. დოკუმენტის სიგანე შემოწმებისას თავსდება ეკრანში. გაზომვები ინახება `P2.8-layout-checks.json` ფაილში. ზოგიერთ ზომაზე ვერტიკალური scrollbar ამცირებს ხილულ შიდა სიგანეს.

შემოწმებულია dropdown, Escape-ით დახურვა, მობილური ნავიგაცია, „ჩემი სივრცე“ ბმული, რეგისტრაციასა და შესვლას შორის გადასვლა, აღდგენის ფორმა და ცარიელი ფორმის ვალიდაცია. განყოფილების ზოგი კადრი მოჭრილია თავად განყოფილების საზღვრებით. შემოწმება მოიცავს გამოყენებულ ბრაუზერსა და ჩამოთვლილ ზომებს.

## საჯარო განთავსება — 2026-11-11

საიტი გამოქვეყნებულია `https://holliday-planner.dynamicabode1.chatgpt.site` მისამართზე. წვდომის რეჟიმია `public`. ანგარიშების სერვისია Supabase. შენახულია საჯარო Site URL და root/`#account` Redirect URL-ები. არსებული ლოკალური მისამართები შენარჩუნებულია.

ავტორიზაციის გარეშე HTTP შემოწმება წარმატებულია — გვერდი, JavaScript და CSS აბრუნებს 200-ს. ბრაუზერში ჩანს მთავარი გვერდი და ანგარიშის ფორმები; შემოწმებისას კონსოლის შეცდომები/გაფრთხილებები არ გამოვლენილა.

- `P2.9-production-home.jpg` — საჯაროდ გახსნილი მთავარი გვერდი.
- `P2.9-production-redirects.jpg` — Supabase-ის ჰოსტინგის პარამეტრების კადრი.
- `P2.9-public-deployment.json` — გამოქვეყნებული ვერსია და HTTP შემოწმების შედეგები.

Supabase-ში custom SMTP გამორთულია. სხვა მომხმარებლების დადასტურების წერილებისთვის ეს სერვისი გასამართია. სრული რეგისტრაცია, ელფოსტის დადასტურება და აღდგენა ამ განთავსების შემოწმებაში გავლილი არ არის.
